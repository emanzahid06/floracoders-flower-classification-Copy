# FloraCoders — Flower Species Classification

## 1. Project Overview
FloraCoders is a flower image classification project. The goal is to develop a machine learning model that predicts the flower species from an input image.

## 2. Dataset
We are using the TensorFlow Flowers dataset, which contains 3,670 labeled images from five classes:
- Daisy
- Dandelion
- Roses
- Sunflowers
- Tulips

## 3. Project Objectives
- Explore and understand the dataset.
- Preprocess images for model training.
- Train and evaluate a baseline deep learning model.
- Compare model performance and select a suitable model.
- Develop an application that uses a trained model to classify flower images.
